# إعدادات التشغيل - Custom Build Command و Custom Start Command

هذا الملف يحتوي على الأوامر المناسبة التي يمكن استخدامها عند إعداد النشر أو التشغيل اليدوي للمشروع.

## 1) Custom Build Command

إذا كان المشروع يستخدم Build Command مخصصًا، استخدم:

```bash
cd backend && npm install
```

أو إذا كان الهدف هو تثبيت الحزم في Backend فقط:

```bash
npm --prefix backend install
```

## 2) Custom Start Command

لبدأ الخادم الخلفي استخدم:

```bash
cd backend && npm start
```

أو بديلًا:

```bash
npm --prefix backend start
```

## 3) ملاحظات مهمة

- المشروع يحتوي على ملف [backend/package.json](backend/package.json) ويبدأ من [backend/server.js](backend/server.js).
- في بيئات النشر مثل Render أو Railway أو أي منصة تدعم Custom Start Command، يمكن استخدام:

```bash
npm --prefix backend start
```

- في حال كانت المنصة تحتاج Build Command منفصلًا، استخدم:

```bash
npm --prefix backend install
```

## 4) إذا أردت تشغيله محليًا

```bash
cd backend
npm install
npm start
```
